Contact

MRRDock is maintained by Simone Ruggiero. There is no company, sales team or support desk behind it: questions reach the developer directly.

Bugs and feature requests

Open an issue on GitHub: https://github.com/simonsruggi/MRRDock/issues. Include your macOS version, the MRRDock version (shown in the popover header) and which platform the source reads. Never paste an API key into an issue.

Email

For anything that should not be public — a security report, a question about how a key is stored, press — write to simone.ruggiero97@gmail.com. Replies usually arrive within a few days.

Security

If you find a vulnerability (for example a way an API key could leave the Keychain), email simone.ruggiero97@gmail.com before opening a public issue, so a fix can ship first.

Support the project

MRRDock is free. If it saves you time, sponsoring on GitHub or starring the repository helps it grow.
