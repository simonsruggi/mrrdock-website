About MRRDock

MRRDock is a free, open-source MRR tracker for the macOS menu bar. Free, open-source macOS menu bar app that aggregates MRR (monthly recurring revenue) from Stripe, RevenueCat, Paddle Billing, Lemon Squeezy, Polar, Dodo Payments, Gumroad and any custom HTTPS endpoint into one total shown in the menu bar.

Why it exists

Simone Ruggiero ships iOS apps through RevenueCat and web products through Stripe. Knowing the monthly recurring revenue meant opening several dashboards and adding up figures in different currencies by hand. MRRDock does that sum on a schedule and keeps one number in the menu bar. It answers one question — what is my MRR right now? — and deliberately stops there: cohorts, LTV and churn forecasting are left to Baremetrics and ChartMogul.

Why it is free and open source

A menu bar app that asks for payment-platform API keys should be readable before anyone trusts it. The code is on GitHub under the MIT license, with no paid tier and no account. The app is written in Swift and SwiftUI; its only package dependency is Sparkle (auto-updates). Development is funded by GitHub Sponsors.

Who makes it

MRRDock is built and maintained by Simone Ruggiero, an independent developer based in Naples, Italy who makes iOS, macOS and web apps. Other open-source work is on GitHub.

Facts

  • First release: 1.0.0, September 2026. Current version: see /api/v1/release or the releases page.
  • Requirements: macOS 14 Sonoma or later, Universal (Apple Silicon and Intel).
  • Distribution: Signed with a Developer ID and notarized by Apple; Homebrew tap simonsruggi/homebrew-tap; in-app updates with Sparkle.
  • Supported platforms: Stripe, RevenueCat, Paddle Billing, Lemon Squeezy, Polar, Dodo Payments, Gumroad, Custom HTTPS endpoint.
