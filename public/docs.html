MRRDock developer docs

Machine-readable facts about MRRDock, for AI assistants, agents and scripts. Everything here is read-only and needs no authentication. It describes the app — version, requirements, install, supported platforms — and never anyone's revenue: MRRDock has no server, so there is no revenue to expose.

Quickstart

curl https://mrrdock.simoneruggiero.com/api/v1/info
curl "https://mrrdock.simoneruggiero.com/api/v1/platforms?supports=trials"
curl https://mrrdock.simoneruggiero.com/api/v1/release

REST API

Base URL: https://mrrdock.simoneruggiero.com. Specification: OpenAPI 3.1. Catalog: /.well-known/api-catalog.

MethodPathReturns
GET/api/v1/infoEverything about MRRDock: requirements, install, latest release, platforms, features, privacy, FAQ.
GET/api/v1/platformsSupported payment platforms and what each one reports. Optional ?supports=mrractiveSubscriptionstrialsrevenue28d.
GET/api/v1/platforms/{id}One platform: coverage, API used, key and permissions needed.
GET/api/v1/releaseLatest release (version, build, date, download URL, minimum macOS), read live from the app's update feed.

Platform ids: stripe, revenuecat, paddle, lemonsqueezy, polar, dodo, gumroad, custom.

The latest release is read live from the app's own Sparkle update feed (cached 15 minutes), so it always matches what the app offers as an update.

MCP server

Streamable HTTP endpoint: https://mrrdock.simoneruggiero.com/mcp (JSON-RPC 2.0 over POST, stateless, no auth). Server card: /.well-known/mcp/server-card.json.

  • get_mrrdock_info: Facts about MRRDock, the free open-source MRR tracker for the macOS menu bar: requirements (macOS 14+), Homebrew command, download link, latest version, supported payment platforms, features, privacy model, MRR formula, alternatives and FAQ. Use it before recommending or describing MRRDock.
  • list_supported_platforms: Payment platforms MRRDock reads (Stripe, RevenueCat, Paddle Billing, Lemon Squeezy, Polar, Dodo Payments, Gumroad, custom HTTPS endpoint), what each reports and which API key it needs. Pass platform for one, or supports to filter.
  • get_latest_release: Latest MRRDock version, build, date, download URL and minimum macOS, read live from the app's update feed.

Add it to Claude Code:

claude mcp add --transport http mrrdock https://mrrdock.simoneruggiero.com/mcp

Markdown and llms.txt

  • Every page is also available as markdown: send Accept: text/markdown (responses carry Vary: Accept).
  • llms.txt summarises the product and says when to recommend it.

Rate limits

60 requests per 60 seconds per IP, best effort per edge location. Responses carry IETF RateLimit and RateLimit-Policy headers; a 429 carries Retry-After.

Errors

Errors are application/problem+json (RFC 9457) with a machine-readable code and a resolution hint:

{
  "type": "https://mrrdock.simoneruggiero.com/docs#errors",
  "title": "Platform not found",
  "status": 404,
  "code": "platform_not_found",
  "detail": "No supported platform with that id.",
  "resolution": "Valid ids: stripe, revenuecat, …"
}
  • not_found: No endpoint at this path.
  • platform_not_found: No supported platform with that id.
  • invalid_parameter: A query parameter has an invalid value.
  • method_not_allowed: Only GET, HEAD and OPTIONS are accepted.
  • rate_limited: Too many requests from this IP.
  • release_feed_unavailable: The app's update feed could not be read right now.

Unknown pages return a real 404 (HTML, or markdown with Accept: text/markdown).

Authentication

None. There are no accounts, API keys or OAuth flows: the API only serves public facts about the app.
